# İçərişəhər Runner

### ▶ [Играть в браузере](https://pavelegrigorev.github.io/iceriseher-runner/)

Браузерный 2D экшн-платформер в духе Aladdin (1993), только вместо Аграбы —
Ичери Шехер, Старый город Баку. Бесконечный процедурный уровень, свободное
управление, сабля, гранаты, качели на коврах и много золота.

Всё рисуется процедурно на `<canvas>`: ни одной картинки, ни одного звукового
файла, ни одной внешней зависимости. Музыка и звуки синтезируются на WebAudio.
Работает с клавиатуры, с геймпада и с телефона.

## Разработка

```bash
npm test          # или: node tests/run.js
```

126 тестов, несколько секунд, без установки чего-либо: исходники исполняются в
`vm`-песочнице с минимальным DOM, так что проверяется ровно тот код, который
идёт в браузер. Покрыты ввод (стик под пальцем, боевые кнопки, мультитач,
клавиатура), физика героя, независимость симуляции от частоты кадров, инварианты
генератора уровня на 45 разных городах, ротация районов и боссов, обе таблицы
рекордов, шаринг, раскладка меню и отрисовка — 2d-контекст в стенде ловит
нечисловые координаты, которые браузер проглатывает молча.

Для агентов и новых сессий: [CLAUDE.md](CLAUDE.md),
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/DECISIONS.md](docs/DECISIONS.md).

## На телефоне

Игра рассчитана на **горизонтальный экран**: в портрете показывается экран
«поверни телефон» с кнопкой «во весь экран» (полноэкранный режим плюс попытка
залочить ориентацию там, где браузер это разрешает).

Логический кадр **адаптивный**: базовые 960×540 растягиваются по той оси, где у
экрана есть запас, поэтому на широком телефоне видно больше улицы, а чёрных
полос нет вообще. HUD на маленьком экране рисуется увеличенным (до 1.45×), а
полоса здоровья босса и таймер ковра уходят из-под больших пальцев.

**Движение — стик под большим пальцем.** Вся левая половина экрана: джойстик
появляется там, где палец коснулся стекла, искать кнопку не нужно. Тяни вбок —
бежать, вниз — подкат и спрыгнуть с навеса. Ход короткий, разворот на бегу стоит
26 px, а если палец уехал через полэкрана, начало стика едет за ним, так что
потянуть обратно можно не отрываясь.

**Действия — кнопки в правом нижнем углу:** гранат и сабля над большой кнопкой
прыжка. Работает мультитач и скольжение пальца между кнопками без отрыва. Кнопки
звука, паузы и полноэкранного режима уезжают наверх по центру, чтобы не спорить
с прыжком.

**Ещё для телефона:** урон и смерть отдают вибрацией (там, где она есть, и
только при включённом звуке); возврат из фона будит звук; кадр, в котором ничего
не изменилось, не перерисовывается — на 120-герцовом экране это вдвое меньше
работы; меню разложены по вкладкам, чтобы влезать без прокрутки. Учитываются
вырезы экрана (`env(safe-area-inset-*)`), отключены зум по двойному тапу,
pull-to-refresh и резиновая прокрутка. Размер буфера отрисовки ограничен, чтобы
не жечь батарею на телефонах с высоким DPR.

## Управление

| Клавиши | Действие |
| --- | --- |
| `←` `→` / `A` `D` | бежать |
| `Пробел` / `↑` / `W` | прыжок; второй в воздухе — двойной |
| `↓` / `S` | подкат на бегу, спрыгнуть с навеса (удерживать), отпустить канат |
| `J` / `Z` / `X` | удар саблей |
| `K` / `C` / `Shift` | бросить гранат |
| `P` / `Esc` | пауза |
| `M` | звук |
| `R` | начать заново |

Работают геймпад и сенсорное управление (см. «На телефоне»). Мир считается
фиксированным шагом 1/60 с, поэтому прыжок одинаков на 60- и 144-герцовом
экране, а результаты в таблице сопоставимы.

## Районы

Бесконечная дорога нарезана на пять районов по 4-7 кусков. У каждого своя
палитра (перетекает плавно), свой набор шаблонов уровня, врагов, препятствий и
реквизита, свой лад и темп музыки. При входе выпадает табличка с названием.

| Район | Что там |
| --- | --- |
| **Qala küçələri** — Улицы крепости | базовый Ичери Шехер: стражники, змеи, псы, жаровни |
| **Karvansaray** — Караван-сарай и базар | галереи на колоннах, ковровые станки, медники, тандыры; пехлеваны, скорпионы, катящиеся кувшины |
| **Damlar üstü** — По крышам | выше, светлее, боковой ветер; вороны, лучники, летучие мыши, осыпающаяся черепица, падающие камни |
| **Hamam və anbar** — Хамам и подземелье | закрытый свод со звёздчатыми люками и лучами света, бирюзовая плитка; мыши, скорпионы, паровые отдушины |
| **Dəniz qapısı** — Морские ворота | Каспий, пальмы, лодки, рыбацкие сети; лучники на стенах и ветер с моря |

## Боссы

Каждый район заканчивается закрытым двором: ворота вперёд не откроются, пока
босс района не падёт. Полоса здоровья с делениями внизу экрана, на половине
здоровья вторая фаза — быстрее и злее. За победу: 1500 очков на множитель
комбо, чай, гранаты, камень, шафран и горсть золота.

| Босс | Район | В чём фокус |
| --- | --- | --- |
| **Qala Sərkərdəsi** — Начальник стражи | Улицы крепости | держит щит спереди: бей со спины или в 1.4 c оглушения после рывка; зовёт подмогу |
| **Bazar Ağası** — Хозяин базара | Караван-сарай | катит кувшины, сыплет монетами веером, прыжком бьёт волной по полу; его самого можно топтать |
| **Qarğa Şahı** — Вороний царь | Крыши | в воздухе достаётся только гранатом, саблей — когда сядет после пике; сбивает ветром и роняет перья |
| **Hamam Divi** — Див из хамама | Хамам | от удара кулаком из пола бьют гейзеры по обе стороны, кидает камни |
| **Xəzər Əjdahası** — Каспийский дракон | Морские ворота | под водой неуязвим, окно — когда высунул голову; плюётся и делает рывок вдоль набережной |

### Финал

За пятым районом дорога выходит на **площадь огня** — ночную арену у костров,
где ждёт **Alov Şahı (Царь огня)**, глыба базальта с лавовыми трещинами и
короной пламени. Три фазы:

- **1** — столбы огня бьют из мостовой линией с одним просветом, плюс веер фаерболов.
- **2** — добавляется вал пламени через всю арену: низкий перепрыгнуть, высокий пройти подкатом. Он кричит, какой именно.
- **3** — сверху сыплются метеоры, паузы между атаками короче.

После каждой атаки у него на груди **раскрывается ядро** на полторы секунды —
попадания в это окно бьют вдвое, полоса здоровья подсвечивается белым.

Победа над ним полностью восстанавливает жизни и гранаты и открывает
**следующий круг**: те же пять районов заново, но сложнее, и у всех боссов
больше здоровья. Круги не кончаются.

## Что происходит на экране

**Бонусы.** Золото — очки. Гранат (нар) — снаряды для броска. Армуду с чаем —
жизнь. Синий камень и шафран — крупные очки. Пахлава — сладкие очки.
Ковёр-самолёт — на 10 секунд даёт планирование (удерживать прыжок в падении) и
магнит для золота.

**Противники.** Стражник — снимается прыжком сверху или саблей; в тюрбане с
золотом «элитный», держит три удара. Змея — низкая и быстрая. Ворона — пикирует
сверху. Уличный пёс — разгоняется и бросается. Скорпион — рывками по земле.
Лучник — стреляет вдоль улицы, стрелу можно отбить саблей. Летучая мышь — висит
под сводом, пока не пройдёшь. Пехлеван с дубиной — три удара, бьёт по земле
волной и прыжком сверху его не снять с одного раза.

**Препятствия.** Шипы, жаровни, качающееся кадило, срывающийся сверху камень,
осыпающаяся черепица (держит полсекунды), катящийся кувшин. Паровая отдушина в
хамаме не ранит, а подбрасывает на следующий уступ.

**Комбо.** Убийства подряд копят множитель на всё, что вы собираете.

**Кувшины** разбиваются саблей, гранатом или прыжком и сыплют золото.

**Канаты с коврами** висят над пропастями: прыгнуть, зацепиться, раскачаться
стрелками, отпустить прыжком.

Падение в пропасть стоит одной жизни и возвращает на улицу; когда жизни
кончились — конец забега.

**Счёт.** У забега один итог — очки: в них уже сложены пройденные метры,
побеждённые враги, собранные трофеи и комбо-множитель. Метры, убитые и золото
показываются только в конце, строчкой подробностей.

**Город меняется каждый день — и сегодня он у всех одинаковый.** Улица, реквизит
и фон выводятся из сида даты, поэтому забеги за один день сравнимы между собой.
Отсюда две таблицы рекордов: «Сегодня» — соревнование в одном и том же городе,
«Всё время» — витрина трофеев. Обе на десять строк, обе в `localStorage` этого
браузера: сервера у игры нет, так что рекорды никуда не уезжают. Результат можно
подписать ником — он запоминается и подставляется в следующий раз.

**Поделиться** забегом можно карточкой: она рисуется на канвасе (со скайлайном
сегодняшнего города) и уходит в системное окно «поделиться», а где его нет —
текстом в буфер обмена.

## Декорации

Фон собирается процедурно из настоящих ориентиров, каждый с подписью:
Девичья башня (Qız Qalası), дворец Ширваншахов с Диванхане и усыпальницей,
Двойные крепостные ворота (Qoşa Qala Qapısı), минарет Сыныг-гала. За
Каспием — Flame Towers, центр Гейдара Алиева, Музей ковра, телебашня.

На игровом плане — таблички настоящих улиц Ичери Шехер, чайхана с самоваром и
армуду, тандыры, ковровые станки, ряды медников, хлебные стойки, нарды, колодцы,
разлетающиеся голуби, коты и кувшины. Палитра построена на абшеронском
известняке: игровой план самый светлый и контрастный, фон уходит в дымку.

## Анимация героя

Скелетная, целиком процедурная, без спрайтов:

- **Squash & stretch** — вытягивается на отрыве от земли, сплющивается на приземлении пропорционально скорости падения.
- **Сальто** на двойном прыжке — полный оборот в воздухе.
- **Приседание при приземлении** с отдачей: колени, руки и папаха просаживаются и возвращаются пружиной.
- **Юз при развороте** на скорости — упор пяткой, наклон корпуса, пыль из-под ног.
- **Разворот, а не зеркало**: спрайт не переворачивается мгновенно, а поворачивается за пару кадров.
- **Удар саблей в три фазы** — замах, быстрый рез, медленная проводка; корпус доворачивает за клинком, дуга следа тянется за лезвием, рот открывается на выдохе.
- **Вторичная анимация**: кушак и серьга тянутся за телом с задержкой, папаха подпрыгивает на приземлении, голова чуть отстаёт от корпуса на разгоне.
- **Бег**: локоть отстаёт от плеча (проводка), амплитуда шага растёт со скоростью, голова покачивается в противофазе, при 250+ px/s за спиной тянутся линии скорости.
- **Простой**: моргает случайно раз в 2.5-6 секунд, а если стоять больше трёх секунд — оглядывается, поправляет папаху, проверяет саблю или потягивается.
- **Урон**: голову откидывает, брови вверх, рот буквой «о», руки взлетают.
- **Смерть**: кувыркается в воздухе.
- **Ковёр-самолёт**: планирующая поза с разведёнными руками.

## Звук

Ни одного аудиофайла — всё синтезируется на WebAudio.

**Музыка** — маленький ансамбль в размере 6/8: нагара (дум и тек) с сбивкой в
конце каждого четвёртого такта, деф на подхвате, бас качает тонику и квинту,
тар выбирает мелодические ячейки из лада района (с мордентами, а не случайным
блужданием), а зурна вступает соло каждые четыре такта. Плотность аранжировки
растёт вместе с дистанцией: сначала только нагара и тар, дальше подключаются
деф, подголоски и зурна.

У каждого района **свой лад, тоника, темп, состав и реверберация**: базар сухой
и быстрый (146), хамам гулкий и медленный (124, без дефа и зурны), площадь огня
самая быстрая (158). В бою с боссом темп поднимается, добавляется низкий пульс.

Всё идёт через сгенерированную пластинчатую реверберацию и лимитер, так что
переулки звучат как переулки, а хамам — как хамам.

**Звуки** — около тридцати голосов. Монеты в серии повышаются по полутону, так
что золотая полоса звучит одной фразой; удар саблей — свист плюс звон клинка;
щит босса даёт металлический clang; ворота открываются низким скрежетом, а за
победу над боссом играет фанфара (за финального — целый туш).

## Структура

```
index.html        разметка, меню, экранные кнопки
styles.css        оформление меню (сама игра рисуется на canvas)
src/core.js       математика, сид-рандом, палитра, константы
src/zones.js      районы и плавное перетекание палитры между ними
src/audio.js      синтез звука и музыка (свой лад на каждый район)
src/input.js      клавиатура, тач, геймпад
src/fx.js         частицы, всплывающий текст, тряска камеры
src/art.js        отрисовка героя, врагов, платформ, декора
src/world.js      параллакс-фон Старого города + генератор уровня
src/entities.js   физика героя, ИИ врагов, снаряды
src/boss.js       шесть боссов (пять районных + финальный), арены и ворота
src/hud.js        HUD на канвасе
src/game.js       состояние игры, правила, главный цикл
```

Генератор уровня складывает бесконечную улицу из шаблонов: улица, пропасть,
лестница, крыши, канаты, базар, крепостная стена, галерея караван-сарая. Какие
шаблоны, враги, препятствия и реквизит выпадут — решает текущий район.
Сложность растёт с дистанцией. Всё, что осталось позади, выгружается из памяти.
